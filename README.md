# 💰 Smart Expense Tracker

A clean and interactive **Expense Tracker** built with **HTML, CSS & JavaScript** to manage daily income and expenses easily.

## ✨ Features

* 💰 Add & manage income
* 💸 Add, edit & delete expenses
* 📊 Automatic balance, income & expense calculation
* 🔍 Search expenses
* 🏷️ Filter expenses by category
* 💾 Data saved using LocalStorage
* 📱 Responsive design

## 🛠️ Technologies

**HTML5 • CSS3 • JavaScript • LocalStorage**
